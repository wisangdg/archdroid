## 3. Temuan & Perbaikan Lingkungan Build

1. **Inkompatibilitas `strip` internal linuxdeploy terhadap SHT_RELR (`.relr.dyn`)**:
   - Binutils terbaru pada Arch Linux mengaktifkan `.relr.dyn` section yang gagal diproses oleh utilitas `strip` bawaan linuxdeploy AppImage.
   - Solusi: build bundler dijalankan dengan `NO_STRIP=1` via script `npm run build:bundles` (`NO_STRIP=1 tauri build`).
2. **Kontaminasi Lingkungan Python oleh AppRun AppImage**:
   - `AppRun` bawaan AppImageKit menginjeksi `PYTHONHOME` dan `PYTHONPATH` menunjuk ke path internal AppDir.
   - Karena bundle AppImage tidak menyediakan runtime Python lengkap, seluruh utilitas host yang berbasis Python (`/usr/bin/waydroid`) mengalami `Fatal Python error: Failed to import encodings module`.
   - Solusi:
     - Implementasi `sanitize_appimage_env()` pada inisialisasi `archdroid_lib::run()` di `src-tauri/src/lib.rs`.
     - Penghapusan eksplisit `PYTHONHOME` dan `PYTHONPATH` pada eksekusi perintah host Waydroid di `src-tauri/src/waydroid.rs`.
     - Ditambahkan unit test pembuktian `sanitize_appimage_env_cleans_polluted_python_vars`.

## 4. Hasil Pengujian di VM Bersih (Arch Linux QEMU/KVM)

### A. Arch Linux Package (`.pkg.tar.zst`)
- **Instalasi**: `sudo pacman -U --noconfirm archdroid-bin-0.1.0-1-x86_64.pkg.tar.zst`
  - Pacman berhasil mengunduh dan memasang dependensi runtime yang belum ada: `webkit2gtk-4.1`, `libappindicator`.
  - File terpasang di `/usr/bin/archdroid`, `/usr/share/applications/ArchDroid.desktop`, `/usr/share/icons/hicolor/*/apps/archdroid.png`.
- **Validasi Desktop Entry**: `desktop-file-validate /usr/share/applications/ArchDroid.desktop`
  - Validasi berhasil dengan status exit 0 tanpa warning/error (`Terminal=false`).
- **Verifikasi Shared Libraries**: `ldd /usr/bin/archdroid`
  - Seluruh dynamic library berhasil di-resolve (`ALL_DEPS_FOUND`).
- **Launch Tanpa Terminal**: `gtk-launch ArchDroid`
  - Berhasil menjalankan aplikasi melalui menu launcher standard, webview terinisialisasi dan merender antarmuka tanpa membuka terminal.
- **Uninstall**: `sudo pacman -R --noconfirm archdroid-bin`
  - Berhasil menghapus semua file aplikasi dan membersihkan desktop/icon caches.

### B. AppImage (`ArchDroid_0.1.0_amd64.AppImage`)
- **Eksekusi Mandiri**:
  - Berhasil dieksekusi baik menggunakan FUSE 2 (`fuse2` terpasang) maupun mode tanpa FUSE (`--appimage-extract-and-run`).
  - Tidak ada popup terminal.
  - Komunikasi dengan host Python (`/usr/bin/waydroid status`) berjalan normal tanpa error encoding Python.

### C. Metadata Paket Debian (`.deb`) & RedHat (`.rpm`)
- `dpkg-deb -I`: Package `arch-droid`, Depends `libwebkit2gtk-4.1-0, libgtk-3-0`, md5sums valid.
- `rpm -qip` & `rpm -qpR`: Name `arch-droid`, Requires `libwebkit2gtk-4.1.so.0()(64bit)`, `libgtk-3.so.0()(64bit)`.
